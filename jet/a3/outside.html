Tag Definition Examples
<!DOCTYPE html> Tells the web browser what version of HTML it is. No examples*
< html lang="en"> Primary language of the page This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English.
< meta http-equiv="refresh" content="0; url=$URL" > Sends the person to a different website. No examples*
<meta charset="UTF-8"> Tells browser what charcter encoding to use. No examples
<title> Title on the browser tab "How to Bake Sourdough"
<style> Section that describes the internal CSS of the page

This is a blue paragraph.
<link rel="stylesheet" href="style.css"> Tag that points to an external CSS file The homepage and this page point to a common style.css file that controls the look of these pages.
<link rel="icon" href="favicon.ico"> Tag that adds a favicon Logo at the left of the pages tab at the top of your browser.
