Common HTML Tags outside <body>

<body> tags

Tag Defenition Examples
<!DOCTYPE html> Tells the web browser to render the page in "Standards Mode" using the HTML5 specification No examples
<html lang="en"> Lets google translate or other translators know what the base language for our site is No examples
<meta charset="UTF-8"> Tells the web browser how to decode the text in your HTML file so it can show letters, symbols, and emojis properly No examples
<meta http-equiv="refresh" content="0; url=$URL"> Instantly redirects the user's browser to $URL No examples
<title> </title> Adds a title to the head of your website
<link rel="" href="link.css"> links the website to another file No examples
<style> </style> Used to change the visual presentation of a webpage The background and font color have changed
<link rel="icon" type="image/x-icon" href="banana.ico"> Adds an image alongside your title
