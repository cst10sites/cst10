Common HTML Tags outside <body>

Tag Definition Examples
<!DOCTYPE html> Declares that the document uses HTML5. !DOCTYPE html
<html lang="*"> Sets page language to a language. <html lang="en"> makes the page language English.
<meta charset="UTF-8"> Sets the character encoding of the webpage. <meta charset="UTF-8">
<meta http-equiv="refresh" content="0; url=$URL"> Redirects to another URL after a set amount of time. <meta http-equiv="refresh" content="5; url=https://google.com"> redirects to Google after 5 seconds.
<title>...</title> Sets the title displayed in the tab. <title>Website</title> makes the website name Website.
<style>...</style> Defines the internal CSS that controls the style of the webpage. <style>
#example { background-color: black; }
</style>
<link rel="stylesheet" href="style.css"> Links to an external CSS file. The homepage and this page can use the same style.css file to control the appearance of both pages.
<link rel="icon" href="favicon.ico"> Adds a favicon, the small icon displayed in the browser tab. <link rel="icon" href="favicon.ico"> makes favicon.ico the website favicon.
