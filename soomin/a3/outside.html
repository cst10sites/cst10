Tags Definition Example
<!DOCTYPE html> Defines the file as html No examples
<html lang="en"> sets the language to the html + begins the html This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English.
<meta charset="UTF-8"> sets the character set of the html This page is set to “UTF-8”.
<meta http-equiv="refresh" content="0; url=$URL"> redirects the user to another page
style="background-color:black; color: white;" An example of internal CSS. This sets the background color of the table item to be black, and the text color to be white Like this
<link rel="stylesheet" href="style.css"> refers to the external CSS in a seperate file
<link rel="icon" type="image/x-icon" href="favicon.ico"> sets the favicon to a specific image
