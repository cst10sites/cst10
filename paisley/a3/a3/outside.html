Tag Definition Examples
<!DOCTYPE html> Declares that the document uses HTML5. No examples*
<html lang="en"> Sets the language of the webpage to English. This page is set to English.
<meta charset="UTF-8"> Sets the character encoding. No examples*
<meta http-equiv="refresh"> Refreshes or redirects a webpage. No examples*
<title>...</title> Sets the title shown in the browser tab. Assignment 3
<style>...</style> Describes internal CSS. This cell has a black background.
<link rel="stylesheet"> Connects an external CSS file. Both pages use styles.css.
<link rel="icon"> Adds a favicon to the browser tab. Look at the browser tab.
