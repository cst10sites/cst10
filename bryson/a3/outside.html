HTML Guide

Common HTML Tags

Tag Definition Examples
<!DOCTYPE html> Makes the page HTML
<html lang="en"> Sets the page's language to English This page is set to "en" for English.
<meta charset="UTF-8"> Lets the page show all letters and symbols
<title>...</title> Sets the title on the tab
<style>...</style> Internal CSS (CSS inside the page) <style>
#black-cell { background-color: black; color: white; }
</style>
<link rel="stylesheet" href="styles.css"> Links to an external CSS file Both pages use the same styles.css file.
<link rel="icon" href="pumpkin.jpg"> Adds the little icon on the tab
