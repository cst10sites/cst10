Common HTML Tags outside <body>


Tag Definition/Explication Example
<!DOCTYPE html> Tells the web browser that your html file is an html5 webpage. N/A
<html lang="en"> Sets the language of the page, which helps tools such as Google Translate know the language the page is using. This page is set to "en" for English
<meta charset="UTF-8"> Sets the character set for the page. N/A
<title></title> Defines the text that goes inside the tab in the web browser.
<style></style> Internal CSS goes inside this tag <style>td.IntCSS {background-color: lightgreen;}</style>
<link rel="stylesheet" href="file name here.css"> Refers your webpage to an external file for external CSS This page refers to style.css for external CSS
<link rel="icon" type="image/x-icon" href="image link"> Adds a favicon, which is the image on the tab of the browser
