Tag Definition Examples
<!DOCTYPE html> Document type declaration. Tells the browser the page is written in HTML5. It must be the very first line. <!DOCTYPE html>
<html lang="en"> Root element that wraps the whole page. The lang attribute sets the page language (here, English). <html lang="en">...</html>
<meta charset="UTF-8"> Sets the character encoding so letters, symbols, and emojis display correctly. <meta charset="UTF-8">
<title> Sets the page title shown in the browser tab. <title>My Web Page</title>
<style> Describes internal CSS written directly inside the HTML file. <style> h1 { color: blue; } </style>
<link rel="stylesheet"> Refers to an external CSS file so many pages can share the same styles. <link rel="stylesheet" href="styles.css">
<link rel="icon"> Includes a favicon, the small icon shown in the browser tab. <link rel="icon" href="favicon.ico">
