Tag Definition Examples
<h1> to <h6> Headings. <h1> is the most important and largest; <h6> is the least important and smallest. <h1>Main Title</h1>
<h2>Subtitle</h2>
<p> Paragraph. Holds a block of text. <p>This is a paragraph.</p>
<a> Anchor (hyperlink). Links to another page or resource using the href attribute. <a href="outside.html">Click here</a>
<img> Image. Displays a picture. It is a self-closing tag that uses the src and alt attributes. <img src="cat.jpg" alt="A cat">
<ul>, <ol>, <li> Lists. <ul> is an unordered (bulleted) list, <ol> is an ordered (numbered) list, and <li> is each list item. <ul><li>Apples</li><li>Oranges</li></ul>
<ol><li>First</li><li>Second</li></ol>
<table>, <tr>, <th>, <td> Tables. <table> creates the table, <tr> a row, <th> a header cell, and <td> a data cell. <table><tr><th>Name</th></tr><tr><td>Sam</td></tr></table>
<div>, <span> Generic containers. <div> groups block-level content; <span> groups inline content. Both are often styled with CSS. <div>A group of elements</div>
<span>a few words</span>
<strong>, <em> Text emphasis. <strong> marks important text (usually bold); <em> marks emphasized text (usually italic). <strong>Warning!</strong>
<em>Really</em> important
<br>, <hr> Breaks. <br> inserts a line break; <hr> draws a horizontal line to separate content. Both are self-closing. Line one<br>Line two
<hr>
<button> Button. A clickable button. <button>Click Me</button>
<form>, <label>, <input> Forms. <form> wraps user input controls, <label> describes a control, and <input> collects data such as text, passwords, or checkboxes. <form><label>Name: </label><input type="text"></form>
